# Joshua Remedial Syeba — Data Scientist & ML Engineer Portfolio

A personal branding portfolio built with Next.js 15 (App Router), TypeScript, Tailwind CSS, and Framer Motion, engineered around an **Arctic Frost** design system inspired by Apple/macOS Material Design Guidelines.

---

## 🛠️ Roles & Focus

- **Data Scientist** — Predictive modeling, statistical inference, feature engineering
- **Machine Learning Engineer** — ML pipeline architecture, model training, evaluation suites
- **Data Engineer** — Scalable ETL pipelines, data validation, database systems
- **Data Analyst** — Business intelligence, data visualization, exploratory analytics
- **AI Engineer** — Applied AI applications, local LLM integrations, model deployments

---

## 🎨 Tech Stack & Architecture

- **Framework**: Next.js 15 (App Router, React Server Components)
- **Language**: TypeScript
- **Styling**: Tailwind CSS, CSS Custom Properties (Arctic Frost Token System)
- **Typography**: Montserrat (Display), DM Serif Display (Editorial Accent), JetBrains Mono (Technical/Metadata)
- **Deployment**: Vercel
- **Design Language**: Apple/macOS HIG Glassmorphism, 4-Corner Orbital Spotlight, Depth Grid Canvas

---

## 🚀 Local Development

```bash
# Clone repository
git clone https://github.com/josjiez/Ingenium.git

# Install dependencies
npm install

# Run dev server
npm run dev

# Production build
npm run build
```

## 📁 Repository Structure

```
├── app/                  # Next.js 15 App Router pages & layouts
│   ├── fonts.ts          # Google Fonts configuration (Montserrat, DM Serif Display, JetBrains Mono)
│   ├── globals.css       # Design tokens, CSS variables, glass specs
│   └── page.tsx          # 9-section portfolio layout composition
├── components/
│   ├── layout/           # Shared layout components
│   ├── sections/         # Portfolio 9 sections (Hero, Intro, About, Tour, Skills, etc.)
│   └── ui/               # Reusable UI primitives (Orbital Spotlight, Photo Frame, etc.)
├── context/              # Project design specs & guidelines (DESIGN.md, RULES.md, etc.)
└── public/               # Static assets & docs
```
