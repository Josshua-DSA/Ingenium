# Folder Assets Gambar Portofolio (`public/docs/`)

Simpan file gambar di folder ini untuk ditampilkan di website portofolio kamu.

### Panduan File Gambar:

1. **Avatar Profile / Foto Diri**:
   * Nama file rekomendasi: `profile.jpg` atau `profile.png`
   * Digunakan pada: Section **Hero** atau **About Me**.
   * Path URL di Next.js: `/docs/profile.jpg`

2. **Gambar Snapshot Proyek / Showcases**:
   * Nama file rekomendasi: `solidus-folium.png`, `waste-classifier.png`
   * Digunakan pada: Section **Featured Projects** / Detail MDX.
   * Path URL di Next.js: `/docs/solidus-folium.png`

3. **Background Texture / Certificates**:
   * Nama file rekomendasi: `certificate-1.png`, `arch-diagram.svg`
   * Path URL di Next.js: `/docs/<nama-file>`
